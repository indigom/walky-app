Walky AdMob 설정 가이드

산책 종료 후 전면 광고 연결 · AdMob 콘솔 화면 기준 · 인쇄용 (A4)
작성 기준: walky-app · Android 패키지 com.anonymous.walkyapp

1. 이 문서에서 쓰는 용어 (3가지만 기억)

이름 모양 어디에 쓰나
앱 ID ca-app-pub-숫자~숫자
물결표 ~ 포함		 Walky 앱 전체를 AdMob에 등록할 때 받는 ID.
PC .env + APK 빌드에 사용
광고 단위 ID ca-app-pub-숫자/숫자
슬래시 / 포함		 「산책 끝 전면 광고」 한 칸의 ID.
PC .env에만 넣음
패키지 이름 com.anonymous.walkyapp Android 앱 고유 주소. Firebase 전용이 아님.
AdMob·Play 스토어·우리 APK가 모두 같아야 함
Play 스토어에 올린 뒤에만 ID가 생기는 것이 아닙니다.
AdMob 웹사이트(admob.google.com)에서 지금 바로 앱을 추가하고 ID를 받을 수 있습니다.

2. AdMob 계정 준비

1
브라우저에서 https://admob.google.com 접속 후 Google 계정으로 로그인
2
처음이면 결제 프로필 안내가 나옵니다 → 국가, 주소, 세금 정보 입력
(나중에 광고 수익을 받을 때 필요. ID 발급과는 별도로 미리 해두는 것을 권장)

3. AdMob 「앱 추가」 화면 — 앱 ID 받기

화면 이동

  1. AdMob 왼쪽 메뉴 「앱」 클릭
  2. 오른쪽 상단 「앱 추가」 (또는 「앱 추가하기」) 클릭

질문 1: 앱이 Google Play 스토어에 있나요?

아직 Play에 안 올렸다면 → 「아니요」 선택
(나중에 스토어에 올려도 AdMob 앱을 다시 연결할 수 있습니다)

질문 2: 플랫폼

「Android」 선택
(iOS는 나중에 출시할 때 별도로 추가)

질문 3: 앱 이름

입력 예: walky 또는 Walky
AdMob 콘솔에서 본인이 알아보기 쉬운 이름이면 됩니다.

질문 4: Android 패키지 이름 ★ 중요

아래 값을 오타 없이 그대로 입력하세요:

com.anonymous.walkyapp

우리 앱 app.json의 android.package와 동일해야 합니다.
Firebase 기준이 아니라 우리 앱의 공식 패키지명입니다.

저장 후 — 앱 ID 복사

  1. 「앱 추가」 완료 후 앱 상세 화면 또는 「앱 설정」으로 이동
  2. 「앱 ID」 항목에서 값 복사
  3. 형태: ca-app-pub-xxxxxxxxxxxxxxxx~yyyyyyyyyy (반드시 ~ 포함)
이 값을 PC 프로젝트에 넣을 곳:
파일: walky-app/.env
EXPO_PUBLIC_ADMOB_ANDROID_APP_ID=여기에_붙여넣기

4. AdMob 「광고 단위 추가」 화면 — 광고 단위 ID 받기

산책을 끝낸 뒤, 결과 화면 직전에 뜨는 전면(Interstitial) 광고용입니다.

화면 이동

  1. AdMob 왼쪽 「앱」→ 방금 만든 walky 앱 클릭
  2. 상단 탭 「광고 단위」 클릭
  3. 「광고 단위 추가」 클릭

광고 형식 선택

「전면」 선택 (영문 화면: Interstitial)
배너·보상형이 아닙니다.

광고 단위 이름

입력 예: 산책종료_전면 또는 post_walk_interstitial
콘솔에서 구분하기 쉬운 이름이면 됩니다.

저장 후 — 광고 단위 ID 복사

  1. 생성 완료 화면 또는 광고 단위 목록에서 ID 확인
  2. 형태: ca-app-pub-xxxxxxxxxxxxxxxx/zzzzzzzzzz (반드시 / 포함)
이 값을 PC 프로젝트에 넣을 곳:
파일: walky-app/.env
EXPO_PUBLIC_ADMOB_POST_WALK_INTERSTITIAL_UNIT_ID=여기에_붙여넣기

5. PC 프로젝트 .env 작성 예시

프로젝트 폴더에 .env 파일이 없으면 .env.example을 복사해 .env로 만듭니다.

# Google AdMob (Walky 산책 종료 전면 광고)
EXPO_PUBLIC_ADMOB_ANDROID_APP_ID=ca-app-pub-xxxxxxxxxxxxxxxx~yyyyyyyyyy
EXPO_PUBLIC_ADMOB_POST_WALK_INTERSTITIAL_UNIT_ID=ca-app-pub-xxxxxxxxxxxxxxxx/zzzzzzzzzz

# iOS 출시 시 추가 (지금은 비워도 됨)
# EXPO_PUBLIC_ADMOB_IOS_APP_ID=ca-app-pub-xxxxxxxxxxxxxxxx~yyyyyyyyyy

6. 무엇을 바꾸면 APK를 다시 빌드해야 하나?

변경한 값 재빌드 필요? 명령 예시
EXPO_PUBLIC_ADMOB_ANDROID_APP_ID
(앱 ID, ~ 포함)		 필요 npm run eas:prod:android
EXPO_PUBLIC_ADMOB_POST_WALK_INTERSTITIAL_UNIT_ID
(광고 단위 ID, / 포함)		 원칙적으로 .env만으로 가능.
앱 ID를 같이 바꿨다면 재빌드		 —
패키지명 변경
(com.anonymous.walkyapp)		 필요 + AdMob·Play도 같이 변경 —

7. 앱에서 광고가 뜨는 흐름

산책 종료 버튼 → PostWalkAd 화면 (광고 로드) → AdMob 전면 광고 전체 화면 표시 → 사용자가 광고 닫기 → 산책 결과 화면 ※ 광고 로드 실패·12초 타임아웃 시 「산책 결과 보기」 버튼으로 건너뜀 ※ Expo Go에서는 동작 안 함 → EAS로 만든 APK 필요

8. 「AdMob 앱 검수」란? (Play 심사와 다름)

구분 무엇인가 언제
AdMob 앱 ID 발급 AdMob에서 앱 추가하면 바로 받음 Play 출시 전 가능
AdMob 검수 실제 광고·수익 허용 여부 검토 결제 프로필·앱 정보 제출 후
Google Play 심사 스토어에 앱 게시 심사 APK/AAB 업로드 후 (별도)
검수 전에는 테스트 광고만 보이거나 광고가 안 뜰 수 있습니다.
개발 중에는 Google 테스트 ID로 동작합니다.

9. 체크리스트 (인쇄 후 체크용)

  • AdMob 로그인 및 결제 프로필 등록
  • 앱 추가 → Android → 패키지 com.anonymous.walkyapp
  • 앱 ID (~ 포함) 복사 → .env의 EXPO_PUBLIC_ADMOB_ANDROID_APP_ID
  • 광고 단위 추가 → 형식 「전면」
  • 광고 단위 ID (/ 포함) 복사 → .env의 EXPO_PUBLIC_ADMOB_POST_WALK_INTERSTITIAL_UNIT_ID
  • npm run eas:prod:android 로 APK 재빌드
  • 폰에 APK 설치 후 산책 종료 → 광고 구간 확인
